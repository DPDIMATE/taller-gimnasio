Taller de Base de Datos – Gimnasio Cuerpo Activo

Descripción

Proyecto académico desarrollado para gestionar la información de un gimnasio mediante una base de datos relacional en PostgreSQL.

Contenido del repositorio

SQL: contiene los 18 scripts desarrollados durante el taller.

base_datos: contiene el respaldo de la base de datos exportado desde pgAdmin 4.

diagramas: contiene el diagrama del modelo de la base de datos.

informe: contiene el informe final en formatos Word y PDF.

correcciones.txt: registra las correcciones realizadas durante el desarrollo.

Herramientas utilizadas

PostgreSQL

pgAdmin 4

Visual Studio Code

Git y GitHub

Diseños y evidencias

Los diseños y evidencias visuales del desarrollo se encuentran incluidos en el informe final en PDF
